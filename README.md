# myFT Engagement & Habit Loop Model

Interactive product strategy artifact illustrating the 4-stage compounding engagement loop built for **myFT** at the **Financial Times**.

# How we won using compounding growth loops

We introduced a combination of light touch onboarding messages peppered across the site that get people either following topics, or setting up alerts. And once they’d set up alerts, this builds the frequency of visit habit.

Our motivation was largely about doing things that increased frequency of visit, rather than, say, increasing pages per visit (volume). The myFT feature-set was built to create [habit loops] (https://www.nirandfar.com/how-to-manufacture-desire/) wherever possible.

We invested hugely, and iteratively in onboarding in order to find the best performing design patterns.

Complementing this we had support from other teams who also encouraged myFT adoption. Product Marketing and CSMs

These ranged from a B2B Knowledge Manager tool, which allowed Knowledge Managers to set up alerts on behalf of a customer, and B2C marketing campaigns that fired when someone performed an event.
Eg You saved an article, you followed first topic.


# Outcomes achieved:
- **+86% Engagement Lift** (RFV vs. control)
- **6x Article Reads** referred by myFT alerts vs. onsite sources
- **+49% Open Rate / +102% uCTR** on event-triggered follow/save onboarding
